## 1. 제목 (Headings)

`#` 개수로 제목 크기를 정합니다. `#` 다음에는 **반드시 한 칸 띄어 씁니다.**

**작성법**

```markdown
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
##### 제목 5
###### 제목 6
```

**결과**

#### 제목 4

##### 제목 5

###### 제목 6

> 💡 제목 1~3은 문서 구조를 흐트러뜨리지 않으려고 결과 예시에서 생략했습니다.

---

## 2. 문단과 줄바꿈

- **문단 나누기:** 빈 줄을 하나 넣습니다.
- **줄만 바꾸기:** 줄 끝에 공백 두 칸을 넣거나 `<br>`을 씁니다.

**작성법**

```markdown
첫 번째 문단입니다.

두 번째 문단입니다.
이 줄은 공백 두 칸으로 줄을 바꿨습니다.  
이 줄은 br 태그로 줄을 바꿨습니다.<br>
끝.
```

**결과**

첫 번째 문단입니다.

두 번째 문단입니다.
이 줄은 공백 두 칸으로 줄을 바꿨습니다.  
이 줄은 br 태그로 줄을 바꿨습니다.<br>
끝.

## 3. 텍스트 강조

| 작성법 | 결과 | 설명 |
|---|---|---|
| `*기울임*` 또는 `_기울임_` | *기울임* | 이탤릭 |
| `**굵게**` 또는 `__굵게__` | **굵게** | 볼드 |
| `***굵게 기울임***` | ***굵게 기울임*** | 볼드 + 이탤릭 |
| `~~취소선~~` | ~~취소선~~ | 가운데 줄 |
| `<u>밑줄</u>` | <u>밑줄</u> | HTML 태그 사용 |
| `<sub>아래</sub>` | H<sub>2</sub>O | 아래 첨자 |
| `<sup>위</sup>` | x<sup>2</sup> | 위 첨자 |
| `<mark>형광펜</mark>` | <mark>형광펜</mark> | 강조 표시 |

## 4. 인용문 (Blockquote)

줄 앞에 `>`를 붙입니다. `>>`처럼 겹쳐 쓰면 안쪽 인용이 됩니다.

**작성법**

```markdown
> 인용문입니다.
>
> > 인용 안의 인용입니다.
> >
> > > 3단계 인용입니다.
```

**결과**

> 인용문입니다.
>
> > 인용 안의 인용입니다.
> >
> > > 3단계 인용입니다.

## 5. 목록 (Lists)

### 순서 없는 목록

`-`, `*`, `+` 중 하나를 씁니다. 들여쓰기(공백 2칸)로 단계를 만듭니다.

**작성법**

```markdown
- 과일
  - 사과
  - 바나나
    - 노란 바나나
- 채소
```

**결과**

- 과일
  - 사과
  - 바나나
    - 노란 바나나
- 채소

### 순서 있는 목록

숫자 뒤에 `.`을 붙입니다. 숫자를 모두 `1.`로 써도 자동으로 번호가 매겨집니다.

**작성법**

```markdown
1. 첫째
2. 둘째
   1. 둘째-하나
   2. 둘째-둘
3. 셋째
```

**결과**

1. 첫째
2. 둘째
   1. 둘째-하나
   2. 둘째-둘
3. 셋째

## 6. 체크리스트 (Task List)

`- [ ]`는 빈 칸, `- [x]`는 체크된 칸입니다.

**작성법**

```markdown
- [x] Git 설치하기
- [x] 첫 커밋 하기
- [ ] 마크다운 마스터하기
```

**결과**

- [x] Git 설치하기
- [x] 첫 커밋 하기
- [ ] 마크다운 마스터하기

## 7. 코드 (Code)

### 인라인 코드

문장 안의 코드는 백틱(`` ` ``) 하나로 감쌉니다.

**작성법:** ``이 명령어는 `git status` 입니다.``

**결과:** 이 명령어는 `git status` 입니다.

### 코드 블록

백틱 세 개(```` ``` ````)로 감싸고, 뒤에 언어 이름을 쓰면 색이 입혀집니다.

**작성법**

````markdown
```python
def hello(name):
    print(f"Hello, {name}!")

hello("Git")
```
````

**결과**

```python
def hello(name):
    print(f"Hello, {name}!")

hello("Git")
```

### 변경 내용(diff) 표시

```diff
- print("old")
+ print("new")
```

## 8. 링크 (Links)

**작성법**

```markdown
[GitHub](https://github.com)
[마우스를 올리면 설명이 떠요](https://github.com "GitHub 홈")
<https://github.com>
[참조 링크][gh]
[목차로 가기](#-목차)

[gh]: https://github.com
```

**결과**

- [GitHub](https://github.com)
- [마우스를 올리면 설명이 떠요](https://github.com "GitHub 홈")
- <https://github.com>
- [참조 링크][gh]
- [목차로 가기](#-목차)

[gh]: https://github.com

> 💡 같은 문서 안의 제목으로 이동할 때는 `#제목-이름`처럼 씁니다. 띄어쓰기는 `-`로, 영어는 소문자로 바뀝니다.

## 9. 이미지 (Images)

링크 앞에 `!`를 붙입니다. `[]` 안의 글자는 이미지가 안 보일 때 대신 나옵니다.

**작성법**

```markdown
![GitHub 로고](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png)
```

**결과**

![GitHub 로고](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png)

크기를 조절하려면 HTML 태그를 씁니다.

```html
<img src="https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png" width="80" alt="GitHub 로고">
```

<img src="https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png" width="80" alt="GitHub 로고">

이미지에 링크를 걸 수도 있습니다.

```markdown
[![GitHub 로고](이미지주소)](https://github.com)
```

## 10. 표 (Tables)

`|`로 칸을 나누고, 두 번째 줄의 `:` 위치로 정렬을 정합니다.

**작성법**

```markdown
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:---|:---:|---:|
| 사과 | 1개 | 1,000원 |
| 바나나 | 12개 | 3,500원 |
```

**결과**

| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:---|:---:|---:|
| 사과 | 1개 | 1,000원 |
| 바나나 | 12개 | 3,500원 |

## 11. 수평선 (Horizontal Rule)

`---`, `***`, `___` 중 하나를 한 줄에 단독으로 씁니다.

**작성법**

```markdown
위 내용

---

아래 내용
```

**결과**

위 내용

---

아래 내용

## 12. 이스케이프 문자

마크다운 기호를 글자 그대로 보여주려면 앞에 `\`를 붙입니다.

**작성법**

```markdown
\*별표가 그대로 보여요\*
\# 제목이 아니에요
```

**결과**

\*별표가 그대로 보여요\*

\# 제목이 아니에요

`\`로 이스케이프할 수 있는 문자: `\` `` ` `` `*` `_` `{}` `[]` `()` `#` `+` `-` `.` `!` `|`

## 15. 알림 박스 (Alerts)

GitHub에서만 보이는 강조 상자입니다.

**작성법**

```markdown
> [!NOTE]
> 참고할 내용입니다.

> [!TIP]
> 알아두면 좋은 팁입니다.

> [!IMPORTANT]
> 꼭 알아야 할 내용입니다.

> [!WARNING]
> 주의가 필요한 내용입니다.

> [!CAUTION]
> 위험할 수 있는 내용입니다.
```

**결과**

> [!NOTE]
> 참고할 내용입니다.

> [!TIP]
> 알아두면 좋은 팁입니다.

> [!IMPORTANT]
> 꼭 알아야 할 내용입니다.

> [!WARNING]
> 주의가 필요한 내용입니다.

> [!CAUTION]
> 위험할 수 있는 내용입니다.

## 17. 수식 (Math)

LaTeX 문법을 씁니다. 문장 안에서는 `$...$`, 한 줄 전체는 `$$...$$`로 감쌉니다.

**작성법**

```markdown
피타고라스 정리: $a^2 + b^2 = c^2$

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

**결과**

피타고라스 정리: $a^2 + b^2 = c^2$

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

## 18. 다이어그램 (Mermaid)

코드 블록 언어를 `mermaid`로 쓰면 GitHub이 그림으로 그려 줍니다.

**작성법**

````markdown
```mermaid
flowchart LR
    A[코드 작성] --> B[저장]
    B --> C[커밋]
    C --> D[푸시]
    D --> E[GitHub]
```
````

**결과**

```mermaid
flowchart LR
    A[코드 작성] --> B[저장]
    B --> C[커밋]
    C --> D[푸시]
    D --> E[GitHub]
```

## 19. GitHub 전용 기능

| 작성법 | 설명 |
|---|---|
| `@사용자이름` | 사용자를 언급(멘션)합니다. |
| `#123` | 123번 이슈나 PR로 링크됩니다. |
| `Closes #123` | PR이 합쳐지면 123번 이슈가 자동으로 닫힙니다. |
| 커밋 해시 (예: `a2d8b6a`) | 해당 커밋으로 링크됩니다. |
| `<kbd>Ctrl</kbd>` | 키보드 키 모양으로 보여줍니다: <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| `<!-- 주석 -->` | 화면에 보이지 않는 메모입니다. |
